# TheRenewGym (spiritual-gym)

Free Christian spiritual-growth web app (installable PWA) at therenewgym.org. Owner: Emadex Creations.

## Stack and workflow
- TanStack Start + React 19 + Tailwind v4 on Cloudflare Workers; D1 `spiritual_gym_db`; R2 `MEDIA` (served at `/media/<key>`);
  Durable Objects `PrayerRoom` (live meetings) and `PushDispatcher`; cron every 5 minutes (`src/lib/cron.ts`).
- Work on a branch → PR → the owner merges and deploys from Windows PowerShell:
  `git pull` · `npx wrangler d1 migrations apply spiritual_gym_db --remote` · `npm run build` · `npm run deploy`.
- Secrets via `npx wrangler secret put …` (never commit `.dev.vars`). Big meetings need `REALTIME_APP_ID`, `REALTIME_APP_TOKEN`.
- `src/routeTree.gen.ts` is regenerated by the build.
- When you add or change a feature: add a line to `src/lib/features.ts` (the public Features page), make sure Admin can see
  and manage it, and add it to the log below.

## Where things live
- Live meetings: `src/hooks/useMeeting.ts` (mesh for Normal ≤12; Cloudflare Realtime SFU for Large ≤50 and Big event ≤300 via
  `src/lib/sfu-client.ts` + `/api/sfu/*` in `src/server.ts`), `src/lib/prayer-room.ts` (room, stage, chat, end time),
  `src/components/MeetingRoom.tsx` (screen, recording sheet), `src/lib/recorder.ts`.
- Community: groups and events are both `prayer_groups` (`is_event = 1` for events). Kinds and per-kind wording:
  `GROUP_KINDS`, `isEventKind`, `spaceOf` in `src/lib/content.ts`. Meeting times: `prayer_schedules` with
  `repeats` = weekly | monthly (nth weekday) | once (`on_date`); maths in `src/lib/schedule.ts`.
- Church meetings: `church_meetings` (`repeats` once | weekly | monthly; the cron adds the next date).
- Daily word: `devotions` table (reflection = multi-paragraph devotion ending "Today: …").
- Picture uploads: best sizes in `src/lib/image-sizes.ts`; resize with `fitImage` (`src/lib/fit-image.ts`) and show
  `<PictureHint kind=… />`. Add any new upload to both.
- New public things for everyone: `announceNew()` (`src/lib/public-news.ts`). Call it when anything new goes public.
- Friends: `src/fns/friends.ts` (friend code/link, requests, invites to read). Respects `user_blocks`.
- Admin alerts: `adminAlert()` (`src/lib/admin-alerts.ts`), categories in `src/lib/alert-types.ts`, page `admin/alerts.tsx`.
- Phone notification checks: `src/lib/push-health.ts`; each device's last result is on `push_subscriptions`.
- Notifications: `src/lib/notify.ts`, `public/sw.js` (focus mode), `src/lib/push-client.ts` (`syncPush` self-repair).
